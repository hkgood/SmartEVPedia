# SmartEVPedia

中国智能电动车软件与智驾演进百科

## 项目简介

SmartEVPedia 是一个专注于收集和整理中国市场上主流智能电动车的座舱和自动驾驶更新信息的开源项目。

### 核心目标

1. **车型信息汇总**：收集各品牌车型的基本尺寸、硬件配置
2. **软件迭代跟踪**：记录OS版本发布时间和新增功能
3. **智驾系统演进**：追踪自动驾驶系统的硬件和软件升级
4. **权威数据源**：以品牌官方渠道信息为主，避免二手信息

### 如何使用

1. **浏览车型**：点击品牌进入，查看各车型详细信息
2. **对比配置**：查看不同车型的硬件配置差异
3. **追踪更新**：关注OS版本历史，了解功能迭代
4. **参与贡献**：通过GitHub提交更新或修正

### 数据原则

- ✅ 以官方发布会、官网、技术白皮书为第一信源
- ✅ 硬件配置取各车型最高配置版本
- ✅ 明确区分车型平台、OS系统、智驾系统的独立更新
- ❌ 不收录用户实测、媒体评测等非官方信息
- ❌ 不进行主观评价，仅记录客观事实

### 技术架构

- **静态站点**：基于 Jekyll + GitHub Pages
- **数据驱动**：YAML 结构化数据存储
- **开源协作**：GitHub 仓库接受 Pull Request
- **持续更新**：定期同步官方发布信息
